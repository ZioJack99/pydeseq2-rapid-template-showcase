# Data and method sources

[GEO GSE159094](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE159094): published PBMC dexamethasone/interferon count data from four healthy donors. The supplementary featureCounts file was verified by SHA-256 before analysis. GEO redistribution does not confer exclusive ownership of the underlying data.

[PyDESeq2 multifactor workflow and threshold-based tests](https://pydeseq2.readthedocs.io/en/stable/auto_examples/plot_minimal_pydeseq2_pipeline.html) document the model and testing approach.

Only aggregate evaluation summaries and original presentation figures are included here. No raw datasets, trained weights or third-party source code are redistributed. Underlying data/software retain their own terms.
